MaxLab Dynamics SSD Life Free

Extract this entire folder, then double-click Start.cmd.
For full SMART access use Start as administrator.cmd or Run as admin in
the app. Approve the Windows consent prompt.

Open README.md for features, source-code instructions, tests and GitHub setup.
Application source is included; no build is needed.

The bundled smartctl reader is a separate GPL-licensed program. Its license
and matching source archive are in third-party/. Keep them with releases.

Remaining SSD endurance is a write-wear estimate, not time until failure.
HDD remaining life is N/A. Unknown fields are unavailable, never assumed 100%.
